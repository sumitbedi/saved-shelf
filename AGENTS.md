# Shelf for LinkedIn saves

Chrome MV3 extension: make LinkedIn saved posts findable (search, collections, notes, sort by real saved date).

Rules: local-only (no backend, telemetry, AI calls, cookies, private LinkedIn endpoints). Never crawl,
auto-click "Show more", save/unsave, like or post. Never modify or hide LinkedIn's own cards. Treat page
text as untrusted (textContent only, never innerHTML from the page).
